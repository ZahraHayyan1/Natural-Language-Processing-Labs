# Natural-Language-Processing-Labs

This repository contains my lab assignments for the **Natural Language Processing (NLP)** course at Imam Abdulrahman Bin Faisal University.

## Topics Covered

The course covers the following topics:

* **Introduction to Natural Language Processing**

  * Overview and applications of NLP
  * Basics of linguistics
  * Essential NLP terminology
  * Language ambiguity and challenges
  * Modern NLP pipelines

* **Text Processing**

  * Text preprocessing and tokenization
  * Text normalization
  * Subword tokenization
  * Byte Pair Encoding (BPE)
  * WordPiece
  * SentencePiece
  * Minimum Edit Distance

* **Language Modeling**

  * N-gram models
  * Perplexity
  * Generalization and zero probabilities
  * Smoothing
  * Text generation

* **Machine Learning for NLP**

  * Supervised learning
  * Naive Bayes
  * Logistic Regression
  * Sentiment classification
  * Topic classification
  * Precision, Recall, and F1-score
  * Dataset splitting and balancing

* **Text Representation**

  * One-hot encoding
  * Bag-of-Words (BoW)
  * TF-IDF
  * Word2Vec
  * GloVe
  * Cosine similarity
  * Bias in word embeddings

* **Deep Learning for NLP**

  * Neural networks
  * Neural language models
  * Embedding layers
  * Cross-Entropy
  * Perplexity
  * Recurrent Neural Networks (RNNs)
  * Long Short-Term Memory (LSTM)

* **Large Language Models**

  * Encoder-only models
  * Encoder-Decoder models
  * Decoder-only models
  * Pretraining objectives
  * Text generation strategies

* **Sequence Labeling**

  * Part-of-Speech (POS) tagging
  * Word classes
  * Hidden Markov Models (HMMs)
  * Viterbi algorithm
  * BIO encoding
  * Named Entity Recognition (NER)

* **Machine Translation and Multilingual NLP**

  * Encoder-Decoder translation
  * Language similarities and differences
  * BLEU evaluation
  * Translation bias

* **Attention Mechanisms**

  * Motivation for attention
  * Query, Key, and Value
  * Computing attention

* **Transformers**

  * Multi-Head Attention
  * Positional Encoding
  * Residual Connections
  * Layer Normalization
  * Transformer architecture

* **Pretrained Models and Transfer Learning**

  * BERT
  * Model-family selection
  * Fine-tuning
  * Parameter-Efficient Fine-Tuning (PEFT)
  * Instruction Tuning
  * Reinforcement Learning from Human Feedback (RLHF)
  * Prompt Design

* **Retrieval-Augmented Generation**

  * Information Retrieval
  * Document representation
  * Sparse and dense retrieval
  * Document chunking
  * Retrieval and generation
  * RAG evaluation

## Repository Structure

Each lab submission is uploaded with its datasets, and supporting files.
